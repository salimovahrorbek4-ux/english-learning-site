# English Mastery — B1 & B2 Learning Platform

Ingliz tilini **B1 (Intermediate)** va **B2 (Upper-Intermediate)** darajada o'rganish uchun bepul ta'lim platformasi.

## Xususiyatlar

### 📖 Darsliklar
- **B1 darajada 10 ta darslik**: Present Perfect, Past Tenses, Conditionals, Passive Voice, Relative Clauses, Modal Verbs, Reported Speech, Comparatives, Gerund vs Infinitive, Articles
- **B2 darajada 10 ta darslik**: Mixed Conditionals, Advanced Passive, Inversion, Cleft Sentences, Advanced Reported Speech, Wish & If only, Subjunctive Mood, Phrasal Verbs, Future Forms, Linking Words

### ✏️ Mashg'ulotlar
- Har bir mavzu bo'yicha **interaktiv mashqlar**
- Tanlash (multiple choice) va to'ldirish (fill-in) mashqlari
- Bir zumda tekshirish va natija ko'rish

### 📝 Testlar
- B1 va B2 uchun **20 ta savollik testlar**
- Savollar orasida erkin harakatlanish
- Batafsil natijalar va tahlil
- Qayta topshirish imkoniyati

## Texnologiyalar
- HTML5, CSS3, Vanilla JavaScript
- Responsive dizayn (mobil qurilmalarda ham ishlaydi)
- Tashqi kutubxonalarsiz — faqat sof HTML/CSS/JS

## Ishga tushirish

Oddiy static fayl — har qanday web serverda ishlaydi:

```bash
# Python bilan
python3 -m http.server 8000

# Node.js bilan
npx serve .
```

Brauzerda `http://localhost:8000` manziliga o'ting.
